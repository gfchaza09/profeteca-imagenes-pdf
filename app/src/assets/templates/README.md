# Plantillas de fondo

Colocá aquí archivos PNG o JPEG exportados desde Stitch u otra herramienta.

1. Copiá el archivo a esta carpeta (por ejemplo `actividades-feed.png`).
2. Editá `manifest.json`:

```json
{
  "templates": [
    {
      "id": "actividades-feed",
      "name": "Actividades — feed",
      "file": "actividades-feed.png"
    }
  ]
}
```

3. Recargá la aplicación. Las plantillas aparecerán en el panel lateral del editor.
